# Python Beginner Challenge

A beginner-level Python assignment containing topic-wise practice exercises and a command-line Student Management System.

## Repository structure

- `fundamentals/` — exercises for variables, data types, conditions, loops, collections, functions, and file handling.
- `student_management/` — menu-driven Student Management System.
- `screenshots/` — sample program-output screenshots.

## Requirements

- Python 3.8 or newer
- No third-party Python packages are required.

## How to run the exercises

Open a terminal in the repository folder and run an exercise, for example:

```bash
python fundamentals/01_variables.py
```

Some exercises ask for input in the terminal.

## How to run the Student Management System

```bash
python student_management/main.py
```

Choose an option from the menu. When adding a student, enter subject marks separated by spaces, for example:

```text
85 90 78 92
```

Records are saved in `student_management/students.json` and remain available the next time the program is run.

## Python concepts used

- Variables and basic data types (`int`, `float`, `str`, `bool`)
- Input and output
- Arithmetic, comparison, and logical operators
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Strings, lists, and dictionaries
- Functions and return values
- File handling with `open`
- JSON data storage
- Error handling with `try` and `except`
